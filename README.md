# 🚀 AI-Powered Developer Portfolio

Welcome to my modern, interactive portfolio! This project is a full-stack application built with React, Vite, Express, and integrated with **Google's Gemini AI** to provide an intelligent, interactive experience for visitors.

## ✨ Features
- **🤖 AI Integration:** Powered by Google's Gemini API for interactive and intelligent site elements.
- **⚡ Lightning Fast:** Built with Vite and React 19 for a highly responsive single-page experience.
- **🎨 Beautiful UI:** Styled with Tailwind CSS v4, Framer Motion for smooth animations, and Radix UI/shadcn components.
- **📱 Fully Responsive:** Carefully designed to work flawlessly on desktop, tablet, and mobile devices.
- **📄 Export to PDF:** Built-in capability to generate and download documents directly from the app.

## 🛠️ Tech Stack
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide React
- **Backend:** Node.js, Express
- **AI / APIs:** `@google/genai`, `@google/generative-ai`
- **Tooling:** ESLint, TypeScript, tsx

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/kanith8206/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Set up Environment Variables
Create a `.env` file in the root of the project (you can use the provided `.env.example` as a template) and add your Gemini API Key:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### 4. Run the Development Server
```bash
npm run dev
```
The application will be available at `http://localhost:3000`.
